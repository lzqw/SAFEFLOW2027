# 最终 DEV 冻结审查（独立评测前）

首批 600K 与有证据支持的 Piper Payload 覆盖候选均已完成注册的新增 100K 终点；所有 DEV 节点、训练计数和失败均已汇总。独立评测尚未运行，以下选择只依据开发集和预先登记的机制判断。

## 冻结选择

- **Piper Reach：首批 P5 100K**。nominal/57.5/60mm 为 30/30、26/30、24/30；相对 control 训练违规下降 68.4%，但 60mm 风险仍为 20%。没有证据值得用最后 100K 继续追逐单个 DEV 节点。
- **Piper Payload：覆盖候选 P5 100K，并保留其 paired control 作为同轮比较**。共同 45/50/55mm 覆盖把 55mm 从首批 P5 的 50.0% 提高到 76.7%，但仍未到 90%；57.5mm 新未见节点为 66.7%。这是一项有方向的改进，不是完全解决。
- **Panda Payload：首批 P5 100K**。nominal/70mm/wide/execution085 为 30/30、30/30、28/30、30/30；宽载荷 93.3% 仍略低于 95%，但训练违规比 control 少 56.5%。

Piper Payload 的覆盖候选只改变训练半径分布，保留原生网络、回放、优化器、P5 设置、Actor 学习率和任务定义；其训练计划 SHA 在 freeze 中单独登记，评估加载器会验证该计划与 checkpoint 内身份一致，不把候选静默当成首批模型。

## 统一独立条件

三条线使用同一冻结后的 target Actor 部署、每条件 100 回合、固定独立布局和动作 seed。Piper Payload 的统一条件为 nominal、55mm、57.5mm、execution085：55mm 对覆盖候选属于训练覆盖，57.5mm 保留为未见几何；首批历史模型不作为本次最终 Piper Payload 选择，但其首批负结果保留在报告中。所有静态接纳失败、违规、超时、完整 horizon 用时和轨迹均保留；独立结果不再反馈训练选择。

本审查只冻结三条最终配对，不宣称达到全部目标。若独立评测仍显示 Payload 几何风险，结论将保留为“覆盖有效但不足”，不消耗最后一个 100K 槽进行无新机制搜索。
