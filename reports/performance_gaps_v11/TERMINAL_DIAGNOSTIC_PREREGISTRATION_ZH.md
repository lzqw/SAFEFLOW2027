# 固定 100K 终点的补充终止动作诊断（先登记，后运行）

首批安全状态诊断没有观察到真实危险动作，不能据此判断失败根因。现登记一批很小的新 DEV 布局，用完整 100K 终点排查 Reach 60mm 与 Payload 55mm 的剩余风险。它不训练、不读独立集、不筛选行为动作。

每任务、每臂固定 8 个新布局，共 32 个回合；全部终止结果保留，早终止不换布局。种子、半径和有限差分 epsilon 见 `performance_gaps_v11_terminal_diagnostic.json`，与旧 DEV/诊断及预留独立种子分离。

行为只来自注册的 target Actor，同一任务两臂逐回合共同 action seed。每个访问动作记录预测/真实全控制区间 margin。仅在该回合终止动作处，从动作前相同 Bullet 状态重放本动作与六个 ±0.05 差分动作，记录梯度、最近保护部件和真实响应；这些标签不参与行为选择，也不更新模型。成功与失败终止都检查，避免只看安全动作。计入全部额外仿真控制和距离查询。

这批小样本用于区分风险值错误、方向错误和提前激活问题；不作为成功率验收，不用少数失败自动批准新训练。只有完整首批 600K 审查和此诊断提供依据时，才登记可选的单因素修正。总新增训练仍不超过 900K。
